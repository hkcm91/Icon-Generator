# Y2K Dream Extras glyph sources

The 48 monochrome source glyphs in `y2k-dream-extras.json` are selected from the bundled Google Material Symbols Rounded Filled library.

- Source project: https://github.com/google/material-design-icons
- License: Apache License 2.0 (see `MATERIAL-SYMBOLS-LICENSE.txt`)
- Role: shape reference only. These vectors establish subject recognition, silhouette, cutouts, and optical balance. The Primary Master Icon remains authoritative for palette, material, lighting, depth, and finish.

Each catalog entry supplies an icon-specific construction note. The generation prompt combines that note with the family-wide mixed-relief rule: a softly raised main form, flush/coplanar color accents, and shallow recessed functional details. This prevents the common failure mode where every component becomes an embossed sticker.
